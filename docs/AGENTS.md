# AGENTS.md — Docs (мокапы и документация)

## docs/mocks/ — HTML/CSS/JS мокапы

9 страниц, чистый HTML/CSS/JS (без сборщиков), открываются в браузере через `file://`.

### Как открыть
```sh
open docs/mocks/index.html
```

### Структура
```
mocks/
├── index.html              # Лендинг
├── catalog.html            # Каталог задач
├── task.html               # Карточка задачи
├── company.html            # Публичный профиль компании
├── how-it-works.html       # Как это работает
├── login.html              # Вход
├── register.html           # Регистрация
├── dashboard-participant.html  # Дашборд участника
├── dashboard-company.html      # Дашборд компании
├── css/styles.css          # Дизайн-система (2030 строк, v2)
└── js/
    ├── auth.js             # Демо-авторизация (localStorage)
    └── theme.js            # Тёмная тема (localStorage)
```

### Особенности
- **Тёмная тема:** `[data-theme="dark"]` + localStorage. Кнопка-переключатель на всех страницах.
- **Авторизация:** localStorage, роль `participant`/`company`. После логина редирект в соответствующий дашборд.
- **Дизайн-система:** accent #166666, card-radius 24px, 52px inputs, Inter/Manrope, стекло-морфизм только для header/popups.
- **Все ссылки** ведут на реальные страницы (кроме 12 пунктов мобильного меню — они работают как заглушки #).
- **Только десктоп** — мобильная версия не адаптирована (это мокапы).

### Когда нужны мокапы
- Чтобы быстро сверить визуал → открой `index.html` в браузере
- Чтобы понять навигацию → кликай по ссылкам (внутренние ведут на реальные страницы)
- Чтобы проверить поведение тёмной темы → нажми кнопку 🌙/☀️
- Чтобы проверить auth flow → заполни форму на `login.html` или `register.html`

### Связь с кодом

В мокапах используется `[data-theme="dark"]`, а в проекте — `.dark` класс на `<html>`.
Это нормально: мокапы — самостоятельный артефакт, не привязанный к реализации.

## DESIGN.md

Дизайн-система проекта (~273 строки). Содержит:
- Полную палитру light + dark (accent `#166666` / `#2EC4B6`)
- Токены цветов (background, surface, text, border, states)
- Типографику (Inter + Manrope, размеры, веса, line-height)
- Сетку и отступы (8pt base)
- Компонентную систему (карточки, кнопки, инпуты, бейджи, табы)
- Принципы стекло-морфизма и теней
- Спецификацию тёмной темы

**Важно:** DESIGN.md — источник истины. Реализация в `globals.css` должна соответствовать DESIGN.md.
