# AGENTS.md — Widgets (FSD слой)

## Роль

Сложные композитные блоки интерфейса. Виджеты собираются из фич, сущностей и shared-компонентов.

**Может импортировать из:** features, entities, shared
**Не может импортировать из:** app

## Структура

```
widgets/
├── header/           # Шапка (навигация, auth, поиск)
├── footer/           # Подвал (ссылки, контакты)
└── task-card/        # Карточка задачи (для каталога и дашбордов)
```

### Шаблон виджета

```
widget-name/
├── index.ts              # публичный экспорт
├── ui/
│   ├── ComponentName.tsx # React-компоненты
│   └── index.ts
└── model/
    └── stores.ts         # Effector stores (если есть)
```

## Правила

1. **Виджеты композитны** — собирают компоненты из фич, сущностей и shared
2. **Нет бизнес-логики** — только отображение, управление UI-состоянием (открыт/закрыт, выбран/не выбран)
3. **Effector stores** — только для UI-состояний (открыто меню, активная вкладка)
4. **Не дублировать фичи** — если сценарий сложный, вынеси в features

## Текущие виджеты

### header
- Логотип, навигационные ссылки
- Поиск (строка)
- Кнопка логина или имя пользователя (в зависимости от `$user`)
- Theme toggle (светлая/тёмная тема)
- Стекло-морфизм: `bg-background/80 backdrop-blur-12`

### footer
- Ссылки: О проекте, Как это работает, Каталог задач
- Контакты, копирайт
- Минимальный, без стекло-морфизма

### task-card
- Карточка задачи для каталога/дашборда
- Заголовок, статус (badge), компания, дата, отклики
- `rounded-3xl` (24px), `bg-card`, `border-border`, `hover:shadow-md`
- `active:scale-[0.98]` на клик

## Важно

- **Не импортировать из app** — виджеты не зависят от роутинга
- **Импорт фич — ок**, но только через публичное API фичи (`index.ts`)
- **Один виджет — одна папка** — не группировать виджеты по общему признаку
