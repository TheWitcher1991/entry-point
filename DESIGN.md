# Design System

> Современная дизайн-система для цифровых продуктов, ориентированных на студентов, молодых специалистов и IT-команды.

---

# Основная идея

Дизайн строится вокруг принципа **"меньше элементов — больше смысла"**.

Интерфейс должен восприниматься легко даже при большом количестве данных. Пользователь не должен искать нужную информацию — она сразу выделяется за счет композиции, размеров карточек, контраста и свободного пространства.

Визуально интерфейс находится между современными SaaS-продуктами, Apple Human Interface и европейскими стартапами.

Это спокойный минимализм с молодежной эстетикой.

---

# Дизайн-принципы

## Большие поверхности

Основной элемент интерфейса — крупная карточка.

Карточка не должна быть перегружена.

Внутри:

- крупный заголовок;
- 1–2 вторичных текста;
- основное действие;
- график либо метрика.

Лучше сделать одну большую карточку, чем четыре маленьких.

---

## Минимум текста

Каждый экран должен читаться за несколько секунд.

Используются:

- короткие заголовки;
- одна строка описания;
- минимум подписей;
- максимум визуальных индикаторов.

Вместо длинных описаний используются:

- иконки;
- статусные бейджи;
- прогресс;
- цвет;
- диаграммы.

---

## Низкая информационная плотность

Интерфейс намеренно "дышит".

Между блоками остается достаточно свободного пространства.

Большие внутренние отступы.

Большие внешние поля.

Никакого ощущения перегруженности.

Свободное пространство является полноценным элементом композиции.

---

## Большие карточки

Практически весь интерфейс строится на карточках.

Карточки имеют:

- большой внутренний padding;
- большие радиусы;
- минимальное количество границ;
- светлый фон.

Карточка должна ощущаться отдельным объектом.

---

## Минимум линий

Разделители используются крайне редко.

Вместо них используются:

- воздух;
- разные уровни поверхности;
- композиция.

---

## Большие радиусы

Практически все элементы имеют мягкое скругление.

Примерные значения:

- Input — 16px
- Card — 24px
- Modal — 28px
- Button — 16–20px
- Widget — 24px

Интерфейс выглядит дружелюбным и современным.

---

# Типографика

Основной инструмент иерархии — размер шрифта, а не жирность.

Используется современный геометрический гротеск.

Рекомендуемые шрифты:

- Inter
- Manrope
- SF Pro Display
- Onest

600–700

20–24 px

Вес 600.

---

16 px

Вес 400–500.

12–13 px

Используются редко.

# Цветовая система

```
#166666
```

Это главный фирменный цвет продукта.

Используется для:

- активных состояний;
- кнопок;
- выделения данных;
- графиков;
- прогресса;
- ссылок;
- переключателей;
- чекбоксов.

Акцентный цвет должен использоваться дозированно.

Белый фон остается доминирующим.

# Иконки

Только outline.

Минимальная толщина.

Без сложных деталей.

Иконка всегда вторична относительно контента.

---

# Кнопки

Основная кнопка

- фон #166666
- белый текст
- крупные внутренние отступы
- радиус 16–18 px

Вторичная

- белый фон
- тонкая граница
- темный текст

Ghost

Без фона.

---

# Формы

Максимально простые.

Большие поля ввода.

Высота:

48–52 px

Без сложных рамок.

При фокусе используется акцентный цвет.

---

# Таблицы

Не классические таблицы.

Используются:

- карточки;
- строки;
- большие отступы;
- минимум линий.

При возможности данные заменяются:

- графиками;
- KPI;
- плитками;
- карточками.

---

# Графики

Используются максимально простые графики.

Без лишних подписей.

Без сеток.

Главная цель — быстро показать тенденцию.

Акцентный цвет:

```
#166666
```

Дополнительные цвета:

светло-серый и белый.

---

# Навигация

Верхняя панель.

Компактная.

Крупные пункты.

Минимум текста.

Используются:

- иконки;
- активная подсветка;
- крупные интервалы между пунктами;
- выпадающие меню для вторичных разделов.

---

# Молодежный стиль

Интерфейс должен выглядеть современно, как цифровой продукт нового поколения, а не корпоративная ERP-система.

Основные признаки:

- крупные заголовки;
- большие карточки;
- много свободного пространства;
- минимум текста;
- плавные анимации;
- мягкие формы;
- спокойная цветовая палитра;
- акцент на визуальное восприятие данных.

Интерфейс должен создавать ощущение легкости, скорости и технологичности.

# Glassmorphism

Glassmorphism используется точечно и только для усиления визуальной иерархии. Он не должен доминировать над интерфейсом.

Допустимые области применения:

- верхняя панель (Top Bar);
- всплывающие меню;
- выпадающие списки;
- модальные окна;
- уведомления;
- командная палитра (Command Palette);
- плавающие панели действий;
- AI-ассистент;
- быстрые фильтры;
- виджеты поверх графиков.

Параметры:

- прозрачность 65–80%;
- background: rgba(255,255,255,0.6–0.8);
- backdrop-blur: 16–24px;
- тонкая светлая граница (1px);
- мягкая тень без высокой контрастности.

Glassmorphism никогда не применяется для всех карточек одновременно — только для интерактивных или поверхностных элементов, чтобы сохранить чистоту и читаемость интерфейса.

---

# Общая атмосфера

Интерфейс должен ассоциироваться со следующими качествами:

- современный;
- спокойный;
- технологичный;
- легкий;
- дружелюбный;
- минималистичный;
- премиальный;
- ориентированный на поколение Z и молодых специалистов.

Главный принцип дизайн-системы:

> **Меньше текста. Больше пространства. Больше визуальной информации. Каждая карточка должна быть самостоятельным, понятным и привлекательным объектом интерфейса.**
