Design System

## Философия

Современная российская дизайн-система для цифровых продуктов, ориентированных на студентов, образование и SaaS. Главные принципы — простота, крупные элементы, минимум визуального шума и максимально понятный UX.

## Основные принципы

- Минимализм без перегруженности.
- Большие карточки вместо плотных таблиц.
- Минимум текста.
- Максимум воздуха.
- Отсутствие теней.
- Крупная типографика.
- Акцент на скорости восприятия.
- Mobile First с качественной десктопной адаптацией.

# Цветовая палитра

## Основной цвет

- Accent: **#166666**

Используется для:

- основных кнопок;
- ссылок;
- активных состояний;
- чекбоксов;
- переключателей;
- индикаторов;
- графиков.

# Карточки

- Без теней.
- Border 1px (#E8E8E8).
- Border Radius: 16–20px.
- Большие внутренние отступы (24–32px).

---

# Кнопки

Высота: 44–48px.

Primary

- фон #166666
- белый текст
- радиус 14–16px

Secondary

- белый фон
- border #E8E8E8
- текст #166666

# UX

- Один главный CTA на экран.
- Не более 3–5 действий одновременно.
- Короткие подписи.
- Вместо таблиц — карточки, списки и таймлайны.
- Большие KPI-блоки с крупными цифрами.

---

# Анимации

- 150–250ms.
- Простые fade и scale.
- Без сложных эффектов.

---

# Общий стиль

Интерфейс должен выглядеть дружелюбно, современно и «молодо», словно мобильное приложение, адаптированное для веба. Основной визуальный акцент — цвет **#166666**, который используется умеренно и только для важных элементов интерфейса.
