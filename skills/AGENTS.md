# AGENTS.md — Проектные скиллы

## Что это

Папка `skills/` содержит проектные скиллы — документированные наборы принципов, паттернов и техник для решения повторяющихся задач.

Каждый скилл — это папка со своим `SKILL.md` и вспомогательными файлами.

## Структура

```
skills/
├── AGENTS.md                              # этот файл
└── make-interfaces-feel-better/           # полировка интерфейсов
    ├── SKILL.md                           # 19 принципов + чеклист
    ├── typography.md                      # типографика
    ├── surfaces.md                        # поверхности, тени, радиусы
    ├── animations.md                      # анимации и переходы
    ├── icons.md                           # иконки
    ├── agents/                            # агенты для авто-применения
    └── performance.md                     # производительность
```

## Как использовать

1. Агент распознаёт задачу, соответствующую скиллу → грузит SKILL.md через `skill` tool
2. Следует принципам и чеклисту
3. Применяет код-паттерны из подпапок

## Доступные скиллы

### make-interfaces-feel-better

Полировка UI: микровзаимодействия, типографика, отступы, тени, анимации.

**Ключевые принципы (из SKILL.md):**
1. `active:scale-[0.96]` на всех кнопках
2. `transition` только конкретных свойств (без `all`)
3. `text-wrap: balance` на h1-h4
4. `text-wrap: pretty` на p, li
5. Концентрические радиусы (24→16→8)
6. Тени вместо бордеров
7. `tabular-nums` для чисел
8. `antialiased` на body
9. 8pt базовая сетка
10. `will-change` только для анимируемых элементов

**Когда применять:**
- Создание/редактирование UI-компонентов
- Страницы с карточками и списками
- Кнопки, ссылки, интерактивные элементы
- Типографика (заголовки, параграфы)
- Формы и инпуты

## Создание нового скилла

1. Создай папку `skills/<skill-name>/`
2. Напиши `SKILL.md` с:
   - Описанием проблемы/контекста
   - Принципами/правилами
   - Примерами кода
   - Чеклистом для проверки
3. Добавь вспомогательные файлы (`typography.md`, `examples/` и т.д.)
4. Создай `agents/` подпапку, если нужны специализированные агенты
5. Обнови `AGENTS.md` в `skills/` — добавь описание нового скилла
